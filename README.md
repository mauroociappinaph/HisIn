# HisIn

English practice for entrepreneurs and healthtech founders. Learners take a CEFR level test, work through modules, practice questions, and review vocabulary with spaced repetition.

## Stack

- Next.js 16 (App Router) + React 19
- Prisma 6 on PostgreSQL
- Tailwind CSS 4
- Gentle Shell (headless `pi` CLI) as the content generation engine

## Setup

1. Install dependencies: `pnpm install`
2. Provide a database URL. Either export `DATABASE_URL`, or put it in `local.env` / `.env.local` at the repo root — `next.config.ts` loads both and real environment variables win:

   ```
   DATABASE_URL=postgresql://user@host:5432/hisin
   ```

3. Apply migrations and seed content:
   ```bash
   pnpm db:migrate
   pnpm seed
   ```
4. Run the app:
   ```bash
   pnpm dev
   ```

## Content generation with Gentle Shell

The app has no LLM SDK and no provider API key. Content is generated by Gentle Shell running headless through the local `pi` CLI, so the machine must have `pi` installed and authenticated.

```bash
curl -X POST http://localhost:3000/api/ai/generate \
  -H 'content-type: application/json' \
  -H "x-service-token: $AI_SERVICE_TOKEN" \
  -d '{"level":"B1","skill":"BUSINESS","type":"MULTIPLE_CHOICE","count":3,"topic":"investor updates"}'
```

Environment:

| Variable | Purpose |
| --- | --- |
| `AI_SERVICE_TOKEN` | Shared secret required by `x-service-token`. Required in production. |
| `AI_ALLOW_LOCAL` | Set to `1` to allow unauthenticated generation in development only. |
| `AI_MODEL` | Override the model, default `gemini-free/gemini-3.1-flash-lite`. |
| `AI_TIMEOUT_MS` | Generation timeout, default `90000`. |
| `AI_CLI` | Override the CLI executable, default `pi`. |

Every attempt is recorded in `GenerationJob`. A generation that fails, times out or returns non-conforming JSON is marked `FAILED` and writes nothing to `Question`.

### Contract that the adapter depends on

- `pi -p` exits `0` even when the provider rejects the request. Failures are read from `errorMessage` in the JSON event stream, never from the exit code.
- `pi -p` reads stdin. The child always gets `stdio: ["ignore", "pipe", "pipe"]`.
- The endpoint spawns an authenticated agent, so it is never public: it is gated by `AI_SERVICE_TOKEN` or the development-only `AI_ALLOW_LOCAL=1`.
- This route needs a persistent Node process with the CLI installed. It does not run on serverless platforms.

## Spaced repetition

Vocabulary reviews use the SM-2 algorithm (`src/modules/vocabulary/srs.ts`). Grades run from 0 to 5; a grade below 3 resets repetitions and schedules the word for tomorrow, and the ease factor never drops below 1.3. Progress belongs to the single persisted local learner (`src/modules/identity/service.ts`).

## Known gaps

- **Listening audio**: `LISTENING_MCQ` questions reference placeholder paths under `/audio/`, and no audio assets exist yet. Until real files are generated, those items cannot be practiced as listening.
- **Authentication**: the app attributes progress to one local learner. There is no sign-up, sign-in or per-user session.
- **Migrations against the real database**: pending migrations must be applied with `pnpm db:migrate` before the SRS and generation features work.
